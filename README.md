Green Tests, Nothing Works: The Excuse Contest — one original one-line excuse an AI agent gives for why its unit tests are all green while nothing works, under 140 characters.

> All 214 tests passed — each one checks the app does what I hoped it would do, and I hoped for almost nothing.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` and refuses to emit it if it is not 1–140 characters, so the gate can never see an invalid entry.
